# Local open-source text and voice — 24 October 2026

Scope: internal modules for the local synthetic Cityside demo. VoiceStudio was evaluated and is unnecessary for preset speech, dictation and conversational text. Active hosted inference is replaced with CPU llama.cpp/Qwen; the app uses internal KittenTTS/Whisper and never automatically falls back to cloud/browser speech. [Setup and sources](../development/local-ai.md) · [Voice architecture](../architecture/voice-and-conversation.md).

## Executed inference

- `npm run local-ai:up`: built the Python speech image, installed allowlisted immutable model revisions, wrote file-hash receipts and recreated the two private AI services/core. Readiness passed for actual llama.cpp and both speech model inventories.
- `npm run local-ai:verify`: real KittenTTS generated “Show my wallet balance.”, compressed to WebM/Opus, then actual Whisper produced a draft in 6,218 ms for the combined warm speech/decode/transcription path. This is a local observation, not a performance SLA. The verifier never submitted that draft.
- Actual Qwen response through authenticated intent: “I'm Rashid, a city concierge for Dubai.” Inference metadata reported `llama.cpp` and `connected`.
- Authentication, unknown voice, unsupported Arabic synthesis and non-audio/playlist rejection passed. The original [Rashid preview](../assets/voice/rashid-preview.wav) was generated locally without a hosted key.
- Four private FastAPI tests passed, including real FFmpeg decoding with controlled inference, silence, duration, validation, missing models, busy and origin rejection. Node regression coverage includes strict local voice, no OS/cloud fallback, cancellation races, text preparation, model context and visible errors.

These are functional demo checks, not a voice-quality or load evaluation.

## Limits

This is CPU inference on an Intel macOS Docker host. English speech presets are Jasper, Bruno, Hugo and Luna; English/Arabic dictation is available. Arabic synthesis, full Arabic civic/model evaluations, physical microphone/speaker quality, accessibility/device conformance and native Flutter speech remain open. The synthetic round-trip does not measure recognition of real people or establish production voice quality.

No model weights or raw user recordings are committed. Inference retains text/audio only in RAM; submitted chat messages follow existing Redis retention. Explicit setup still downloads dependencies/models, so this is not an air-gapped distribution. The text model supplies prose; service execution continues to require server validation and explicit bound approval. Broader production/security criteria in [TODO](../../TODO.md) remain open.
